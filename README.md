# LowPoly Редактор - 3D редактор низкополигональных моделей

Браузерный 3D редактор для создания низкополигональных моделей. Построен на Three.js с использованием TypeScript и Vite.

## Возможности

- Создание примитивов: куб, сфера, цилиндр, плоскость, конус
- Регулировка количества полигонов с помощью ползунка
- Орбитальное управление камерой (вращение, панорамирование, зум)
- Система отмены/повтора действий
- Панель свойств объекта (позиция, вращение, масштаб)
- Палитра цветов для изменения цвета объектов
- Подсчёт вершин и граней в реальном времени

## Установка

```bash
npm install
```

## Запуск (режим разработки)

```bash
npm run dev
```

## Сборка

```bash
npm run build
```

## Предпросмотр сборки

```bash
npm run preview
```
